Intelligent Monitoring System

With precise analysis functions, anyone can easily check the status of the power plant, enabling stable and efficient operation.
Data-based automated management prevents declines in generation efficiency and delays in responding to abnormalities.

Key Features
Real-Time Monitoring
  • Real-time measurement of each string’s status using environmental sensors (panel/external temperature, irradiance) and output sensors (voltage, current)
Generation Abnormality Analysis
  • Determines abnormalities by comparing with historical data
  • Distinguishes temporary abnormalities (clouds, etc.) from permanent abnormalities (panel failure)
  • Identifies the scope of issues by differentiating local and overall abnormalities
Natural Disaster Detection
  • Detects disasters such as typhoons and earthquakes using wind speed, vibration, and tilt sensors
Automatic Control & Reporting
  • Shuts down output of the affected string in case of permanent abnormality
  • Sends abnormality alarms to the control server to support rapid administrator response
